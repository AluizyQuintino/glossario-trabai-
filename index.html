Glossário Interativo de Termos Técnicos

JavaScript
Linguagem de programação usada principalmente no desenvolvimento web para criar interatividade em páginas.
Sinônimos: JS, ECMAScript, linguagem de script
implementação
Processo de colocar em prática ou desenvolver uma solução, algoritmo ou funcionalidade.
Sinônimos: execução, aplicação, desenvolvimento
desenvolvendo
Ato de criar, construir ou aprimorar um software, sistema ou funcionalidade.
Sinônimos: criando, programando, construindo
Undefined
Valor especial em JavaScript que indica que uma variável foi declarada, mas ainda não recebeu valor.
Sinônimos: indefinido, não definido, sem valor
contador
Variável usada para contar ocorrências, iterações ou controlar loops.
Sinônimos: acumulador, índice, marcador
